# Formatting shortcuts, sampling artefacts and domain leakage in seven public phishing URL benchmarks

Code, per-run results and LaTeX source for the article of the same title by Osman Can Çetlenbik (Manisa Celal Bayar University).

The study audits seven public phishing URL corpora (Ebbu2017, PhishStorm, ISCX-URL2016, PT-Alexa, Hannousse2021, PhiUSIIL, Kaggle-MU). It measures how much reported accuracy comes from how the strings were recorded, from homepage-only legitimate classes and from registered domains shared between training and test data. The experiments cover within-corpus and cross-corpus detectors, a character CNN, thresholds set on validation data, and SHAP attribution.

## Layout

- `code/`: all scripts (Python 3.13).
- `results/`: per-run JSON/CSV files, run logs, `numbers.json` (every number in the paper), `provenance.json` (mirror commits and SHA-256 digests) and `code_sha256.json` (digests of the code that produced them).
- `manuscript/`: LaTeX source; `macros.tex` and `tables/` are generated by `code/make_tables.py`.

The raw URL files are not redistributed. The result files hold no URL strings from the corpora, only n-grams and registered-domain names.

## Reproducing

```bash
pip install -r code/requirements.txt
URLDS_ROOT=$HOME/ds bash code/fetch_data.sh   # clones the mirrors at the audited commits and checks digests
bash code/run_all.sh                          # audit, linear/tree models, controls, transfer, SHAP, tables, figures
bash code/run_cnn.sh                          # character CNN
bash code/finalize.sh                         # audit, aggregation, tables, figures, code digests
```

Runtimes on four cores: about 43 minutes for the linear and tree models, 1.8 hours for the CNN, 46 minutes for the third-review controls and 4 minutes for the attribution analysis. Seeds are fixed in each script; set `OMP_NUM_THREADS=1` as the run scripts do.

## Data sources

PhishTank, UCI (PhiUSIIL, CC BY 4.0) and the GitHub mirrors listed in `results/provenance.json`. Each source keeps its own terms; see the article's data statement.
